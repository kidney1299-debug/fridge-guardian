# 냉장고 파수꾼

냉장고 속 식재료를 기한이 가까운 순서로 관리하고, 가진 재료로 만들 수 있는 요리를 추천하는 모바일 우선 PWA입니다. 첫 버전은 로그인이나 서버 없이 브라우저 `localStorage`에만 데이터를 저장합니다.

**배포 주소:** https://kidney1299-debug.github.io/fridge-guardian/

## 주요 기능

- 식재료 이름, 보관 방법, 수량, 단위, 유통기한 등록
- 냉장·냉동·실온 분류와 유통기한 임박 순 자동 정렬
- 이름 검색, 보관 방법 및 처리 상태 필터
- 사용 완료·폐기 처리와 기록 보관
- 현재 보유 재료와의 일치율에 따른 기본 요리 추천
- 사용률, 폐기율, 7일 내 임박 재료를 보여주는 낭비 리포트
- 모바일 하단 내비게이션과 데스크톱 사이드바를 갖춘 반응형 UI
- 앱 설치 및 오프라인 재방문을 지원하는 웹 앱 매니페스트와 서비스 워커
- 처음 실행하면 바로 둘러볼 수 있는 샘플 데이터 제공
- 카카오톡 등 모바일 공유 시트로 전달하는 서버 없는 가족 공유 링크
- 링크를 누른 뒤 한 번의 확인으로 끝나는 중복 방지 병합

## 시작하기

Node.js 20 이상과 npm이 필요합니다.

```bash
npm install
npm run dev
```

개발 서버는 기본적으로 `http://localhost:5173`에서 실행됩니다.

## 검증 명령

```bash
# 단위 및 UI 테스트
npm test

# TypeScript 검사와 프로덕션 빌드
npm run build

# 빌드 결과 미리보기
npm run preview
```

## 데이터 저장 방식

식재료 데이터는 현재 브라우저의 `fridge-guardian-items-v1` 키에 JSON으로 저장됩니다. 다른 브라우저나 기기와 동기화되지 않으며, 브라우저 데이터를 삭제하면 함께 사라집니다. **낭비 통계 → 샘플 데이터 다시 채우기**에서 언제든 초기 샘플로 되돌릴 수 있습니다.

## 가족에게 공유하기

홈 또는 식재료 화면의 **공유** 버튼을 누르면 휴대폰의 기본 공유 시트가 열립니다. 카카오톡 등으로 받은 링크를 누르면 가져올 식재료를 확인하고 **목록 병합하기** 한 번으로 추가할 수 있습니다.

- 현재 `보관 중`인 식재료만 공유하며 사용·폐기 기록은 제외합니다.
- 공유 데이터는 짧은 형태로 변환하고 압축한 뒤 URL의 해시(`#share=...`)에 담습니다.
- URL 해시는 일반적인 웹 요청에서 서버로 전송되지 않으며, 별도 공유 서버나 계정이 필요하지 않습니다.
- 동일한 ID 또는 이름·보관 방법·유통기한이 같은 식재료는 병합할 때 자동으로 건너뜁니다.
- 실시간 동기화 방식은 아니므로 변경된 현황은 새 링크로 다시 공유해야 합니다.

## 프로젝트 구조

```text
src/
├── data.ts                 # 날짜에 맞춰 생성되는 샘플 데이터와 요리 목록
├── hooks/useFoodStorage.ts # localStorage 상태 관리
├── lib/food.ts             # 정렬, 필터, 추천, 통계 도메인 로직
├── App.tsx                 # 화면과 사용자 상호작용
└── styles.css              # 모바일 우선 반응형 디자인
public/
├── manifest.webmanifest    # PWA 메타데이터
├── sw.js                   # 오프라인 캐시 서비스 워커
└── icons/                  # 앱 아이콘
```

## 참고

- 서비스 워커는 프로덕션 빌드에서만 등록됩니다. PWA 동작은 `npm run build && npm run preview`로 확인하세요.
- 요리 추천은 외부 API가 아닌 앱에 포함된 기본 레시피와 단순 재료 일치율을 사용합니다.
- 서버로 전송되는 사용자 데이터는 없습니다.
